# 矩阵乘示例驱动的系统主图：讨论稿 v1

以用户提供的两张参考图为排版与内容层次参考：采用有标题条的分区、明确模块边界、
代码片段及反馈箭头；内容对应本项目的约束搜索与分级筛选。

- 输入：A/B 到 MatMul 再到 C 的 DAG，及有正确初始化的朴素三重循环。
- 变换：分块、重排、缓存、线程绑定，展示调度后循环片段。
- 模块一（蓝）：CS 约束采样、H 在回放前后硬筛，原后处理/Verify 保留。
- 模块二（橙）：GA 内 Draft 粗评分、跨代归档与入围候选、GA 后通用代价模型精筛。
- 后端：lowering、代码生成、编译；CUDA 路径用 S-TIR → CUDA → PTX/cubin 示意。
- 实测：更新数据库和代价模型，反馈后续批次；最终输出最佳候选的二进制。

代码是结构示意，调度后片段省略了索引还原、初始化、共享内存加载、同步及写回；
As/Bs 表示共享内存分块，c 表示局部累加器，不应当作可直接运行的完整 CUDA kernel。
Verify 内的 lowering 用于合法性检查，后端编译路径仍需实际 lowering/代码生成。

单栏宽约78.3 mm，高182.0 mm。PDF用于论文；SVG保留可编辑文字；PNG用于讨论预览。
`figure.tex` 是对应的单栏插图片段，当前为独立讨论稿。
重绘脚本：`experiments/draw_architecture_matmul.py`（从项目根目录运行）。
